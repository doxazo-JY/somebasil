# 카페 썸바실 관리 시스템 — 사용 가이드

> 이 파일은 `lib/guide.ts`에서 만들어요 (사이트 /guide 화면, 비서 AI와 같은 내용). 직접 고치지 말고 guide.ts를 고친 뒤 `npx tsx notes/_make_manager_guide.ts`.

## 공통

### 처음 쓰는 법 (`/`)

왼쪽 메뉴는 운영 · 분석 · 데이터 세 묶음이에요. 위쪽 탭으로 묶음 안의 화면을 오가요.

**언제:** 처음 한 번

- **운영** — 매장 굴리기 — 대시보드 · 주간 · 사무실 · 직원. 매일·매주 보는 화면
- **분석** — 깊게 보기 — 손익 · 지출 · 메뉴. 왜 적자인지, 뭘 바꾸면 되는지 찾는 화면
- **데이터** — POS 매출·통장·근무일지 같은 파일을 넣고, 잘못 들어간 걸 고치는 화면
- **기간 선택** — 연·월(또는 주)을 바꾸면 다른 화면으로 옮겨 가도 같은 기간이 유지돼요
- **오른쪽 아래 로고 버튼** — 비서 AI에게 바로 물어보기. "이번 달 매출 지난달이랑 비교해 줘", "시급 어디서 바꿔?"처럼
- **화면 제목 옆 ?** — 그 화면 가이드로 바로 가요
- **폰** — 대시보드·주간·사무실·직원은 폰에서도 잘 보여요. 데이터 고치기처럼 표가 큰 화면은 PC에서 써 주세요

**자주 하는 일**

- **매주 수요일 밤에 할 일** → 데이터 화면에 POS 매출 파일과 통장 파일을 끌어다 놓기 → 체크리스트가 다 차면 경영 AI가 지난주를 분석 → 목요일 회의 전에 주간 화면에서 확인
- **매월 말에 할 일** → 근무일지 엑셀을 데이터 화면에 올리기 → 직원 화면에서 그달 인건비 확인 → 근무일지 엑셀 받아서 세무사에게 전달

## 운영

### 대시보드 (`/`)

이번 달 상황을 한 화면에. 열자마자 매출·지출·이익과 적자 신호가 보여요.

**언제:** 매일 아침

- **맨 위 한 줄 요약** — 이번 달 가장 중요한 변화 한 줄
- **숫자 카드** — 매출 · 지출 · 이익 등. 카드를 누르면 자세한 화면으로 가요
- **적자 신호** — 손익을 깎아 먹는 원인 후보 (원가율 등은 메뉴 원가가 충분히 채워지면 켜져요)
- **매출 달력** — 날짜별 매출. 유난히 낮은 날은 원인을 찾아보는 출발점
- **카테고리 · 인기 메뉴** — 무엇이 많이 팔렸는지
- **메모** — 그달 있었던 일 한 줄 (신메뉴 출시, 휴무 등) — 손익 화면 월별 표에도 같이 보여요

**자주 하는 일**

- **지난달 보기** → 위쪽 연·월 선택에서 바꿔요
- **그달 특이사항 남기기** → 메모 카드에 적어요

### 주간 (`/weekly`)

목요일 주간회의 자료 한 장. 지난주(월~일) 숫자와 경영 AI 분석·이번 주 추천이 같이 보여요.

**언제:** 매주 목요일 회의 전

- **경영 AI가 본 이 주** — 매출·통장을 올리면 경영 AI가 지난주를 보고 꼭 볼 것 3가지를 정리해요. 처리(확인 완료)는 사무실에서. 분석이 없는 주에는 대신 자동 요약 한 줄이 나와요
- **이번 주 추천** — 수요일 아침 경영 AI가 계절·기념일과 우리 카페 흐름을 보고 주는 추천 1~2개
- **숫자 카드** — 매출 · 지출 · 이익 · 객단가(1회 결제 평균) · 주문 수, 전주와 비교
- **요일별 · 카테고리 · 인기 메뉴** — 어느 요일이 약했는지, 무엇이 팔렸는지

**자주 하는 일**

- **다른 주 보기** → 오른쪽 위 주 선택
- **분석이 안 나와 있어요** → 데이터 화면 체크리스트에서 지난주 매출·통장이 일요일까지 다 들어왔는지 확인. 다 들어오면 자동으로 분석해요

### 사무실 (AI 업무팀) (`/inbox`)

AI 6명이 일하는 사무실. 누르면 그 AI가 올린 챙길 일만 오른쪽에 보여요.

**언제:** 매일 · 알림이 있을 때

- **경영 AI** — 매출·통장을 올리면 지난주 꼭 볼 것 3가지 + 마케팅 AI에게 이번 주 주제 넘기기. 수요일 아침 이번 주 추천. [지난주 다시 분석] = 데이터를 고쳐 올린 뒤 다시 보기. [기획 요청] = 주제를 적으면 기획안 (비우면 이번 주 추천)
- **마케팅 AI** — 경영 AI 주제나 직접 요청한 주제로 인스타·블로그 초안. 마케팅 화면에서 고치고 승인
- **비서 AI** — 궁금한 걸 물어보면 기록을 찾아보고 답해요. 오른쪽 아래 로고 버튼으로 어느 화면에서나 물을 수 있어요
- **자금 관리 AI** — 통장을 올리면 앞으로 30일 잔고가 부족해질 위험을 알려요 (주 1번)
- **직원 관리 AI** — 매일 아침 퇴근 누락과 주휴수당 대상을 찾아요 (AI 비용 없음)
- **원가 AI** — 매주 월요일, 원가 계산이 막힌 곳(재료 가격·수제 재료 배합·메뉴 레시피)을 물어봐요. 질문 카드에 편하게 답을 적고 [정리하기] → 미리보기 확인 → [이대로 저장]
- **그림 속 모습** — 책상에서 타이핑 = 작업 중 · 자리에서 서류 = 확인 기다림 · 카페에 있음 = 할 일 없음
- **챙길 일 카드** — [확인 완료] = 처리함, [숨기기] = 안 봐도 됨. 처리한 항목은 아래 "처리한 항목 보기"에서 되돌릴 수 있어요

**자주 하는 일**

- **인스타 글 쓰기** → 사무실에서 마케팅 AI → [마케팅 화면에서 글 쓰기], 또는 경영 AI 분석 후 자동 초안 확인
- **AI가 언제 일하나** → 매일 아침 8시 직원 관리 · 월요일 원가 · 수요일 경영 추천 · 매출·통장 올린 직후 경영(→마케팅)·자금 관리

### 마케팅 (`/marketing`)

마케팅 AI가 쓴 인스타·블로그 초안을 고치고 승인해서 직접 올려요. 자동으로 올리지는 않아요.

**언제:** 초안이 올라왔을 때

- **새 글 초안** — 맨 위 한 줄. 무엇에 대한 글인지 적으면 인스타·블로그 초안을 같이 써요
- **확인할 초안** — 2열 카드. 인스타/블로그 탭으로 바꿔 보고 바로 고칠 수 있어요. [대괄호] 칸은 AI가 지어내지 않고 비워 둔 곳 — 채운 뒤 승인
- **순서** — 고치기 → [승인] → [복사하기] → 인스타·블로그에 붙여 넣고 올리기 → [올렸어요]
- **올린 글** — 다 올린 주제는 아래 "올린 글"로 접혀요

**자주 하는 일**

- **마케팅 화면 가는 길** → 운영 > 사무실 > 마케팅 AI 책상 > [마케팅 화면에서 글 쓰기] (탭은 따로 없어요)

### 직원 (`/staff`)

출퇴근과 인건비. 근무 탭에서 이번 달 근무·급여를, 직원·설정 탭에서 직원 목록과 QR·시급을 관리해요.

**언제:** 수시 (퇴근 누락 고치기) · 월말 (인건비·근무일지 엑셀)

- **근무 탭 · 기준 기록** — 같은 날 종이 근무일지와 QR 기록이 둘 다 있으면 어느 쪽으로 계산할지 (종이 우선 / QR 우선). 한쪽만 있으면 있는 쪽. 바꾸기는 직원·설정 탭
- **근무 탭 · 숫자 카드** — 그달 근무시간 · 인건비(고정급·주휴 포함) · 근무 인원 · [근무일지 엑셀] (세무사 전달용, 그달까지 누적)
- **근무 탭 · 직원별 n월 (날짜별)** — 종이 근무일지와 같은 모양. 파란 점 = QR, 회색 점 = 종이, 주황 = 퇴근 누락, 분홍 줄 = 주일(1.5배). QR 칸을 누르면 고치기, 빈 칸을 누르면 직접 입력 (종이 칸은 읽기만)
- **근무 탭 · 직원별 n월 (사람별)** — 한 줄 = 한 사람의 그달 합계. 누르면 날짜별 출퇴근과 고정급·주휴수당 넣기
- **근무 탭 · 전체 근무일지** — 지난달들까지 월별 근무시간·지급액 (접혀 있음)
- **직원·설정 탭 · 직원 목록** — 이름 바꾸기(동명이인은 김민지A처럼) · 직책 · 등록된 폰 · [연결 QR] · 퇴사 처리/복직 · 삭제(테스트 직원 정리용)
- **직원·설정 탭 · 매달 고정급** — 점장처럼 매달 같은 금액. 적용 시작 달부터 인건비·근무일지 엑셀에 자동. 그 달에 근무일지로 들어온 고정급이 있으면 그걸 써요
- **직원·설정 탭 · 카운터 QR · 시급** — 매장에 붙여 둘 출퇴근 QR(출력용), 평일·주일 시급 (바뀌면 적용 날짜와 함께 추가)

**자주 하는 일**

- **퇴근 누락 고치기** → 근무 탭 날짜별 보기에서 주황 칸을 눌러 퇴근 시간 넣기 (원래 QR 시간도 남아요)
- **새 직원 QR 등록** → 직원이 카운터 QR을 처음 찍으면 이름을 넣고 바로 등록돼요
- **이미 목록에 있는 직원(근무일지로 들어온 직원)·폰을 바꾼 직원** → 직원·설정 탭 → 그 직원 [연결 QR] → 직원 폰 카메라로 찍기 (10분, 1회용). 연결되면 바로 출근 화면이 떠요
- **출퇴근 찍는 법 (직원)** → 카운터 QR을 찍으면 3분 동안 출근·퇴근 버튼이 열려요. 한 번 누르면 닫히고, 다음에는 다시 QR을 찍어야 해요. 집에서 링크로 열면 현황만 보여요
- **시급 바꾸기** → 직원·설정 탭 → 시급에서 적용 날짜와 평일·주일 시급 추가
- **QR로 완전히 넘어가기** → 직원·설정 탭 → 기준 기록을 QR 우선으로
- **세무사에게 보낼 근무일지** → 근무 탭 [근무일지 엑셀]

## 분석

### 손익 (`/profit`)

올해 돈이 얼마 남았는지(월별 손익)와 흑자가 되려면 뭐가 바뀌어야 하는지(흑자 조건).

**언제:** 월말 · 대표 미팅 전

- **월별 손익 보기** — 올해 누적 매출·지출·이익, 월평균 이익, 추이 그래프, 월별 표(메모 포함)
- **흑자 조건 보기** — 최근 3개월 평균으로 손익분기 월매출, 하루 매출 목표, 하루 필요 고객 수, "하나만 바꾼다면" 표(고객 수·객단가·재료비율·고정비), 목표 이익별 필요 매출, 시간대별 매출 vs 알바 인원
- **흑자 조건 · 기준 줄** — 숫자 카드 아래에 "7~9월 평균 기준"과 달별 인건비가 어디서 왔는지(근무 기록 / 통장 급여) 보여요. 인건비는 그 달에 일한 만큼(직원 화면 계산)을 쓰고, 근무일지가 없는 달만 통장 급여(보통 다음 달 지급이라 전달분)를 써요. 다른 곳에서 계산한 손익분기와 다르면 대부분 이 인건비 차이예요
- **매출 기준** — 이익을 POS 매출로 볼지 통장 입금으로 볼지는 데이터 > 데이터 고치기 > 계산 기준에서

**자주 하는 일**

- **다른 해 보기** → 오른쪽 위 연도 선택

### 지출 (`/expenses`)

돈이 어디로 나갔는지. 통장 출금이 재료비·인건비·고정비 등으로 나뉘어 보여요.

**언제:** 월말

- **지출 추이** — 카테고리별 월 지출 변화
- **원가율 카드** — 매출 대비 재료비 비율 등
- **거래처별 합계 · 항목 목록** — 누구에게 얼마나 나갔는지

**자주 하는 일**

- **분류가 잘못된 출금 고치기** → 데이터 > 데이터 고치기 > 통장 거래 분류에서 카테고리 바꾸기

### 메뉴 (`/menu`)

언제 무엇이 팔리는지(판매 패턴)와 메뉴 한 잔·한 개를 만드는 데 드는 돈(원가).

**언제:** 메뉴판 정리 · 가격 고민할 때

- **판매 패턴 · 요일×시간 표** — 진할수록 매출이 많은 시간대. 알바 배치·발주 참고
- **판매 패턴 · 죽은 메뉴** — 고른 기간에 거의 안 팔린 메뉴 — 메뉴판 정리 후보
- **원가 보기** — 메뉴별 원가·마진·원가율. 단가가 빠졌거나 레시피가 없는 메뉴는 따로 표시돼요. 원가 AI가 빈 곳을 물어봐서 채워요
- **재료 회수율** — 재료 한 봉지 값을 메뉴 판매로 얼마나 회수했는지 (원가가 충분히 채워지면 켜져요)

**자주 하는 일**

- **원가 채우기** → 사무실 원가 AI 질문에 답하기, 또는 레시피 엑셀 양식을 데이터 화면에 올리기
- **안 파는 메뉴 정리** → 데이터 > 데이터 고치기 > 메뉴 목록에서 비활성

## 데이터

### 데이터 (`/upload`)

받은 파일을 끌어다 놓으면 종류를 알아보고 바로 저장해요. 잘못 들어간 건 아래 데이터 고치기에서.

**언제:** 매주 수요일 밤 (매출·통장) · 월말 (근무일지)

- **지난주 체크리스트** — 지난주 매출·통장이 어디까지 들어왔는지. 둘 다 일요일까지 차면 경영 AI가 분석을 시작해요
- **파일 넣기** — POS 일일매출 · 하나은행 거래내역 · POS 메뉴 목록 · 근무일지 · 레시피 양식. 파일 이름은 그대로, 여러 개 한꺼번에 OK. 같은 파일을 다시 넣어도 중복되지 않아요
- **분류가 애매한 통장 출금** — 규칙에 안 걸려 재료비(카드)로 넣은 출금. 틀린 것만 바꾸면 돼요. 통장을 다시 올려도 고친 분류는 남아요
- **데이터 고치기 · 통장 거래 분류** — 달별 전체 출금의 카테고리 수정
- **데이터 고치기 · 메뉴 목록** — POS 이름과 메뉴 연결, 안 파는 메뉴 비활성
- **데이터 고치기 · 수동 조정** — 통장으로 자동 분류가 안 되는 수입·지출을 달별로 더하거나 빼기 (사비 대납 등)
- **데이터 고치기 · 계산 기준** — 이익을 POS 매출 기준으로 볼지 통장 입금 기준으로 볼지 · 합계가 이상할 때 [재계산]

**자주 하는 일**

- **POS 매출 파일을 다시 올리기** → 그냥 다시 끌어다 놓으면 돼요. 파일에 매출이 있는 날짜는 파일 내용으로 맞춰져요 (취소된 주문·0원 줄이 정리돼요). 파일에 없는 날짜는 건드리지 않아요
- **근무일지를 고쳐서 다시 올리기** → 그냥 다시 끌어다 놓으면 그 달들이 새 파일 내용으로 바뀌어요 (예전 근무일지 파일을 넣으면 그 사이 고친 내용이 덮이니 주의)
- **데이터 고치기가 안 보여요** → PC 화면에서만 보여요
