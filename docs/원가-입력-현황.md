# 메뉴 원가 입력 현황 (점장님용)

> 카톡으로 받은 레시피 정보를 시스템에 직접 넣은 기록 + 아직 필요한 정보.
> 엑셀(레시피 템플릿)로 같은 이름의 재료·메뉴를 다시 올리면 **엑셀 내용이 우선**합니다. 이 문서에 있는 것만 따로 올리실 필요는 없어요.

마지막 업데이트: 2026-10-07

---

## 1. 이번에 시스템에 넣은 것

### 직접 만드는 재료 (서브레시피)

"만드는 데 쓴 돈 ÷ 만들어진 양"으로 1단위당 원가를 계산해요.

| 만드는 재료 | 들어간 것 | 만들어진 양 | 1단위 원가 |
|---|---|---|---|
| 더치원액 | 더치커피 원두 1kg (40,000원) | 5,000ml | **1ml당 8원** |
| 복숭아 아이스티 원액 | 립톤 아이스티 믹스 4.5kg (32,000원) + 로즈마리 5.6g (1,013원) | 69잔분 | **1잔분 478원** |
| 망고 아이스티 원액 | 민트라벨 망고 아이스티 3kg (28,000원) + 로즈마리 3.7g (675원) | 46잔분 | **1잔분 623원** |

- 뜨거운 물, 소금처럼 값을 매기기 어려운 건 뺐어요 (원가 영향 거의 없음)
- 로즈마리는 재료 하나라서 단가를 첫 번째 정보(5.6g = 1,013원, 1g당 약 181원)로 통일했어요. 망고 쪽 정보(3.7g = 675원)와 1잔당 0.01원도 차이 안 나요

### 메뉴 원가 결과

| 메뉴 | 판매가 | 원가 | 원가율 |
|---|---:|---:|---:|
| 더치커피 원액 450ml | 18,000원 | 3,600원 | 20.0% |
| 더치커피 원액 260ml | 10,000원 | 2,080원 | 20.8% |
| 복숭아아이스티 | 4,000원 | 478원 | 12.0% |
| 망고아이스티 | 4,000원 | 623원 | 15.6% |

⚠ 위 원가에는 **병·컵·뚜껑 같은 포장재가 아직 빠져 있어요.** 아래 2번 ⑤⑥ 참고.

### 단가만 먼저 넣어둔 재료 (자몽청용)

| 재료 | 구매 정보 | 1g당 |
|---|---|---:|
| 자몽 농축액 | 3.6kg = 72,000원 | 20원 |
| 자일로스 설탕 | 3kg = 7,596원 | 2.5원 |
| 올리고당 | 500g = 1,286원 | 2.6원 |

자몽(3kg = 14,000원)은 원래 등록돼 있었어요. **완성량만 알면 자몽청 원가가 바로 계산돼요** (아래 ①).

### 단가 적용 시점
새로 넣은 단가는 모두 **2025-12-15부터** 적용했어요 (기존 재료들과 같은 기준). 그래서 지난달 분석에도 같은 가격이 쓰여요.
가격이 오르거나 내리면 **언제부터 얼마인지** 알려주세요. 날짜별로 따로 저장돼서 예전 달 원가는 그대로 남아요.

## 2. 점장님께 확인 부탁드릴 것

| # | 질문 | 왜 필요한가요 |
|---|---|---|
| ① | **자몽청 한 번 만들면 완성된 게 총 몇 g이에요?** (재료 무게 합 말고, 다 만들고 통에 담은 무게) | 재료값 약 95,000원을 이 무게로 나눠야 자몽에이드·자몽티 원가가 나와요. 다음에 만들 때 저울로 한 번만 재주세요 |
| ② | **더치커피(ICE)·더치라떼 한 잔에 원액 몇 ml 넣어요?** | 원액 1ml = 8원이라 양만 알면 바로 계산돼요 |
| ③ | **"아이스티"(4,000원) 메뉴는 복숭아아이스티랑 같은 건가요?** | POS에 "아이스티", "복숭아아이스티"가 따로 있어요. 같으면 같은 레시피로 묶을게요 |
| ④ | **설탕 단가** (얼마짜리를 몇 g 사는지) | 제조크림에 설탕이 들어가는데 단가가 없어서, 흑임자크림 → 흑임자슈페너 원가가 막혀 있어요. 설탕만 채우면 풀려요 |
| ⑤ | **콜드컵 뚜껑 단가** | 아이스 음료 포장세트(컵·뚜껑·홀더) 중 뚜껑 값만 비어 있어요. 컵 46원, 홀더 89원은 있어요 |
| ⑥ | **아이스티 "빨대·컵·뚜껑 포함 1잔 477원 / 621원"이 맞나요?** | 원액값만 나눠도 477원 / 621원이 나와요 (33,013원 ÷ 69잔, 28,675원 ÷ 46잔). 그래서 **컵·뚜껑·빨대 값은 실제로는 안 들어간 숫자**로 보여요. 컵·홀더만 더해도 1잔에 약 135원(+뚜껑값) 더 나와요. 빨대도 쓰시면 빨대 단가도 알려주세요 |

## 3. 시스템 쪽 남은 작업 (점장님이 하실 일 아님)

- 아이스티 메뉴는 이름에 "ICE"가 없어서 아이스 포장세트(컵·뚜껑·홀더)가 **자동으로 안 붙고 있어요.** ⑤ 뚜껑 단가를 받으면 같이 고칠게요
- "수제 재료 안에 또 수제 재료"(흑임자크림 ← 제조크림)도 이제 계산돼요. 남은 건 ④ 설탕 단가뿐이에요
